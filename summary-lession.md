1. Khởi tạo playwright:
- Câu lệnh: npm.cmd init playwright@latest

2. Khởi tạo git
- git init

3. Cấu hình tên git:
- nếu cấu hình chung trên máy cho all projects: git config --global user.name 
"tên"
- nếu chỉ muốn cấu hình cho project hiện tại: git config user.name "tên"
- lỡ tạo cho global thì bỏ bằng cách: git config --global --unset user.name "tên"

4. Tạo 1 repo trên github

5. Sau khi tạo xong sẽ có ssh

6. Chạy lệnh để liên kết project và repo: git remote add origin https://github.com/nguyenthidiem-qc/bba-test01.git
